# 등유 안심 · 울주군 시범 프로토타입

기름이 떨어지기 전에 먼저 전화하는 AI. 한국석유공사 AI·데이터 서포터즈 팀 유일무이의 기름알리미 분야 B 시연용 웹 데모입니다.

기온과 배달 기록으로 집마다 등유가 떨어지는 날을 예측하고, 그 전에 AI가 어르신께 먼저 연락해 동의하시면 주문을 넣어 드립니다. 예상 소진일이 지났는데 주문이 없는 집은 생활지원사에게 "살펴봐 주세요"로 알립니다.

## 화면

| 경로 | 쓰는 사람 | 내용 |
|---|---|---|
| `/` | 모두 | 소개, 핵심 숫자, 실제 자료와 가상 자료 구분 |
| `/households` | 생활지원사·가족 | 가상 가구 3곳(상북 A, 두서 B, 두동 C)의 잔량 그래프, 알림일, 소진일, 겨울 부족액. 첫 겨울 집 계수 계산기 |
| `/call` | 어르신 | AI 전화(또는 AI 스피커) 대화 시뮬레이션. 버튼, 직접 입력, 음성 인식, 음성 읽기. 가족 카카오톡 승인 |
| `/dealer` | 판매소 | 주문 확인 → 배달 완료 입력 → 집 계수 다시 학습. 이번 주 소진 예상 마을, 오늘 가격 입력 |
| `/dashboard` | 울주군 | 읍면 개략도, 살펴봐 주세요, 한파 위험, 겨울 부족액, 배관 우선 마을 근거(에너지 정책 탭) |

화면끼리 이어집니다. AI 전화에서 주문 → 판매소에 뜸 → 배달 완료 → 가구 잔량과 현황판이 바뀜. 상태는 브라우저 `localStorage`에만 저장됩니다(상단 "시연 초기화").

## 모델

```
남은 기름 = 마지막 배달 뒤 탱크 양 − Σ(기본 사용량 + 집 계수 × 그날 난방도일)
난방도일 = max(0, 18℃ − 일평균기온)
```

- 알림: 잔량이 "앞으로 7일 쓸 양 + 50L" 아래로. 7일 안 한파 신호가 있으면 70L (01 모델검증 모의실험 근거)
- 살펴봐 주세요: 예상 소진일 7일 뒤에도 주문 없음, 또는 통화에서 기름값 부담을 말함
- 학습: 눈금 답변(30%), 배달량(50%)으로 집 계수 보정
- 숫자는 `src/lib/model.ts`가 계산하고, 대화(`src/lib/dialog.ts`)는 그 값을 문장에 넣기만 합니다

## 생성형 AI (Gemini)

- `/api/chat`: 어르신 대답을 Gemini(`gemini-3.5-flash-lite`)가 이해해 의도(눈금, 승낙, 거절, 양 변경, 돈 부담, 질문 등)를 JSON으로 돌려줍니다. 공감 한마디와 질문 답변도 만듭니다.
- 주문·연결 같은 행동은 화면의 단계 규칙이 정합니다. 주문은 항상 "다시 확인 → 네" 두 단계를 거칩니다.
- LLM 문장에 사실 목록(모델 계산값)에 없는 숫자가 있으면 버립니다. 공감 한마디에는 숫자를 허용하지 않습니다.
- 키가 없거나 호출이 실패하면 규칙 분류로 자동 대체합니다(화면 상단 배지에 표시).

## 자료

| 등유 주유소 39곳 가격 | 오피넷 전국개별주유소가격 (2026-09-19) | `scripts/build_stations.py` → `src/data/stations.json` |
| 읍면별 65·75·80세 이상 | 공공데이터포털 울주군 노인인구 현황 (2025-08-20) | `src/data/ulju.ts` |
| 가구, 판매소, 바우처 잔액 | **가상** | `src/data/households.ts` |

## 실행

```bash
cp .env.example .env.local   # GEMINI_API_KEY, OPINET_API_KEY 입력
npm install
npm run dev     # http://localhost:3000
```

## 배포 (Vercel)

GitHub에 올린 뒤 Vercel에서 저장소를 Import 합니다. Project Settings → Environment Variables에 `GEMINI_API_KEY`, `OPINET_API_KEY`를 넣고 다시 배포합니다. 함수 지역은 서울(`icn1`, `vercel.json`)입니다.
